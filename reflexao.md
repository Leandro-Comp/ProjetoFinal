# Reflexão e Análise Crítica do Aprendizado

Durante o curso de Fundamentos de Git e GitHub, compreendi a importância do controle de versão distribuído para manter o histórico organizado e seguro.


## Principais Aprendizados
- **Conventional Commits:** Padronizar mensagens facilita a leitura do histórico e a rastreabilidade das alterações.
- **Branches e Pull Requests:** Trabalhar isoladamente fora da branch main evita conflitos diretos e permite revisar o código antes da integração.
- **Issues:** Vincular tarefas ao código com palavras-chave como closes #N organiza o fluxo de desenvolvimento.


## Conclusão
A prática integrada consolidou tanto os comandos locais no terminal quanto a colaboração remota no GitHub, culminando na publicação do portfólio via GitHub Pages.
