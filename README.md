# Projeto Integrador Final - Git e GitHub

Portfólio oficial desenvolvido para consolidar os fluxos locais e colaborativos trabalhados no curso de Fundamentos de Git e GitHub (CEFET-MG).


## Tecnologias e Práticas Aplicadas
- Git & GitHub
- Conventional Commits
- Fluxo de Branches e Pull Requests
- Gestão de tarefas com Issues
- HTML5 & CSS3 para GitHub Pages
